# 编码规范

## TypeScript 规范

### 1. 类型定义

**优先使用 interface 而非 type**：

```typescript
// ✅ 推荐
interface MattressListing {
  id: string;
  title: string;
  price: number;
}

// ❌ 避免（除非需要联合类型或映射类型）
type MattressListing = {
  id: string;
  title: string;
  price: number;
};
```

**枚举使用**：

```typescript
// ✅ 推荐：字符串枚举
type MattressSize = "1.2m" | "1.5m" | "1.8m" | "King" | "Custom";

// ✅ 推荐：固定值枚举
type MattressCondition = "Brand New" | "Like New" | "Very Good" | "Excellent" | "Good";
```

### 2. 类型导入

```typescript
// ✅ 推荐：使用 type 导入
import type { MattressListing } from "@/types";

// ✅ 混合导入
import { getListings, type MattressListing } from "@/utils/db";
```

## React 规范

### 1. 组件定义

**使用函数组件 + TypeScript**：

```typescript
// ✅ 推荐
interface HeaderProps {
  currentCity: string;
  onCityClick: () => void;
  favoritesCount: number;
}

export default function Header({ currentCity, onCityClick, favoritesCount }: HeaderProps) {
  return <header>...</header>;
}
```

### 2. Hooks 使用

**自定义 Hooks 命名以 `use` 开头**：

```typescript
// ✅ 推荐
function useAppContext() {
  const context = useContext(AppContext);
  if (!context) {
    throw new Error("useAppContext must be used within an AppContextProvider");
  }
  return context;
}
```

**useCallback / useMemo 优化**：

```typescript
// ✅ 推荐：稳定函数引用
const toggleFavorite = useCallback((id: string) => {
  setFavorites((prev) => {
    // ...
  });
}, []);

// ✅ 推荐：缓存计算结果
const currentListings = useMemo(() => {
  return initialListings.filter(/* ... */);
}, [initialListings, citySlug, searchQuery]);
```

### 3. 客户端组件

**明确标记 "use client"**：

```typescript
// ✅ 推荐：文件顶部标记
"use client";

import React, { useState } from "react";

export default function CityBrowseClient() {
  // ...
}
```

## Next.js 规范

### 1. 路由结构

```
app/
├── [city]/           # 动态路由
├── listing/[id]/     # 嵌套动态路由
├── api/              # API 路由
└── page.tsx          # 页面组件
```

### 2. 服务端组件 vs 客户端组件

| 类型 | 默认 | 标记 | 用途 |
|------|------|------|------|
| 服务端组件 | ✅ | 无 | 数据获取、SEO、静态内容 |
| 客户端组件 | ❌ | `"use client"` | 交互、状态、浏览器 API |

### 3. Server Actions


## Tailwind CSS 规范

### 1. 类名组织

```tsx
// ✅ 推荐：按功能分组
<button
  className="
    bg-black text-white           /* 背景 + 文字 */
    px-5 py-2.5 rounded-full      /* 间距 + 圆角 */
    hover:bg-neutral-800          /* 交互状态 */
    transition-all active:scale-95 /* 动画 */
    font-semibold text-[13px]     /* 排版 */
  "
>
  发布
</button>
```

### 2. 响应式设计

```tsx
// ✅ 推荐：移动优先
<div className="
  flex flex-col        /* 移动端：纵向 */
  md:flex-row          /* 桌面端：横向 */
  gap-4 md:gap-6       /* 响应式间距 */
">
```

### 3. 避免任意值

```tsx
// ❌ 避免
<div className="w-[350px] h-[200px]">

// ✅ 推荐：使用 Tailwind 预设值
<div className="w-80 h-48">
```

## Git 提交规范

### 提交消息格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

### 类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| feat | 新功能 | `feat(listing): 添加商品收藏功能` |
| fix | 修复 | `fix(city): 修复城市切换闪烁问题` |
| docs | 文档 | `docs: 更新 API 设计文档` |
| style | 样式 | `style(header): 优化导航栏响应式布局` |
| refactor | 重构 | `refactor(db): 重构数据库查询逻辑` |
| perf | 性能 | `perf(listing): 使用 useMemo 优化列表过滤` |
| test | 测试 | `test(api): 添加收藏 API 单元测试` |
| chore | 构建/工具 | `chore: 更新依赖版本` |

### 示例

```bash
feat(listing): 添加商品发布功能

- 实现 PostListing 组件
- 添加图片上传功能
- 支持 Supabase 和本地双写存储

Closes #123
```

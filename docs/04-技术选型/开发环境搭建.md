# 开发环境搭建

## 环境要求

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | >= 18.17.0 | 推荐使用 LTS 版本 |
| npm | >= 9.0.0 | 或使用 pnpm/yarn |
| Git | >= 2.30 | 版本控制 |
| VS Code | 最新 | 推荐编辑器 |

---

## 快速开始

### 1. 克隆项目

```bash
git clone <repository-url>
cd mattress-marketplace
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量

复制环境变量模板：

```bash
cp .env.example .env.local
```

编辑 `.env.local`：

```env
# Supabase 配置（可选，不配置则使用本地降级模式）
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key

# 阿里云 OSS（可选，用于图片 CDN 加速）
NEXT_PUBLIC_ALIYUN_OSS_BUCKET=your-bucket
NEXT_PUBLIC_ALIYUN_OSS_REGION=oss-cn-hangzhou
NEXT_PUBLIC_ALIYUN_OSS_CDN_URL=https://cdn.example.com
```

### 4. 启动开发服务器

```bash
npm run dev
```

访问 [http://localhost:3000](http://localhost:3000)

## 常见问题

### 1. 端口被占用

```bash
# 使用其他端口
npm run dev -- -p 3001
```

### 2. Node.js 版本过低

使用 nvm 管理 Node 版本：

```bash
nvm install 18
nvm use 18
```

### 3. Supabase 连接失败

- 检查 `.env.local` 配置是否正确
- 确认网络可以访问 Supabase
- 系统会自动降级到本地模式

### 4. 图片上传失败

- 检查 Supabase Storage 是否配置
- 系统会自动降级到 Base64 存储

# Restored — 床垫二手交易平台

## 项目概览

**项目名称**：Restored（MattressMarket）
**技术栈**：Next.js 14 + TypeScript + Supabase + Tailwind CSS
**创建日期**：2026-06-06
**当前阶段**：MVP 已完成，核心功能全部实现

## 功能完成状态

| 模块 | 状态 | 说明 |
|------|------|------|
| 城市浏览 | ✅ 完成 | 50+ 城市、IP 自动定位、动态路由 |
| 商品发布 | ✅ 完成 | 完整表单、图片上传、Server Action 写入 |
| 商品详情 | ✅ 完成 | 图片画廊、规格参数、联系卖家 |
| 收藏管理 | ✅ 完成 | localStorage + Supabase 双端同步 |
| 消息通知 | ✅ 完成 | 联络申请、降价通知、全部标已读 |
| 城市定位 | ✅ 完成 | 太平洋 IP 定位、cookie 持久化 |
| 鉴权系统 | ✅ 完成 | HttpOnly Cookie + Supabase RLS |
| 降价功能 | ✅ 完成 | 卖家一键降价、收藏用户通知 |
| 响应式设计 | ✅ 完成 | 移动端/桌面端适配 |
| 降级策略 | ✅ 完成 | Supabase ↔ localStorage 三层降级 |

## 下一步建议

| 优先级 | 方向 | 说明 |
|--------|------|------|
| P0 | 搜索与筛选 | 当前城市浏览页缺少关键词搜索、价格区间、多维度筛选 |
| P0 | 商品管理 | 卖家无法编辑/下架/重新上架自己的商品 |
| P1 | 图片存储 | 当前图片上传逻辑需优化，接入 Supabase Storage |
| P1 | 用户认证 | 接入微信/手机号登录，替代 device_id 匿名追踪 |
| P2 | 测试覆盖 | tests 目录为空，补充单元测试和 E2E 测试 |
| P2 | 部署上线 | 配置生产环境、CI/CD 流程，部署到 Vercel |

# Restored — 床垫二手交易平台

## 项目概览

**项目名称**：Restored（MattressMarket）
**技术栈**：Next.js 14 + TypeScript + Supabase + Tailwind CSS
**创建日期**：2026-06-06
**当前阶段**：MVP 已完成，核心功能全部实现；暗色模式 / next/image / SEO 元数据收尾完成

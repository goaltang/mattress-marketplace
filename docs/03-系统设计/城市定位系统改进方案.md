# 城市定位系统设计与实现

> **文档状态**：本方案已落地实现。代码位于 `src/config/cities.ts`、`src/app/api/locate/route.ts`、`src/hooks/useGeolocation.ts`、`src/context/AppContext.tsx`、`src/components/CityChooseModal.tsx`、`src/components/LocationPrompt.tsx`。最后更新于 2026-06-14。

## 1. 设计目标

1. **提升定位精度**：优先使用浏览器 H5 地理定位，IP 定位作为兜底。
2. **增强国内可用性**：引入高德 IP/逆地理编码服务，按高德 → ip-api → ipinfo.io 顺序兜底。
3. **统一城市标识**：全局统一使用 lowercase `slug`，消除 `currentCity` 大小写混用问题。
4. **扩展城市覆盖**：引入 `china-division` 全国行政区划数据库，替代硬编码城市列表。
5. **细化定位失败处理**：区分“权限拒绝”“定位超时”“城市未覆盖”“网络错误”等场景，给出对应提示与降级策略。
6. **保持非强制跳转体验**：首次访问以静默 IP 定位 + 推荐气泡为主，不强制跳转。

## 3. 城市数据源

### 3.1 依赖

```bash
npm install china-division pinyin-pro
```

- `china-division`：全国省市区行政区划数据
- `pinyin-pro`：将中文城市名转换为拼音 slug

### 3.2 生成逻辑

```ts
// src/config/cities.ts
import pc from "china-division/dist/pc.json";
import { pinyin } from "pinyin-pro";

const MUNICIPALITIES = new Set(["北京市", "天津市", "上海市", "重庆市"]);

// 同名城市 slug 冲突处理
const SLUG_OVERRIDES: Record<string, string> = {
  "宿州市": "suzhou-ah",
  "抚州市": "fuzhou-jx",
  "泰州市": "taizhou-js",
  "伊春市": "yichun-hlj",
  "玉林市": "yulin-gx",
};

function generateSlug(rawName: string): string {
  if (SLUG_OVERRIDES[rawName]) return SLUG_OVERRIDES[rawName];

  let base = rawName
    .replace(/自治州$/, "")
    .replace(/地区$/, "")
    .replace(/盟$/, "")
    .replace(/市$/, "");

  // 自治州去掉民族后缀，保留地名前缀
  const ethnicRegex = new RegExp(`^(.+?)(?:${ETHNIC_GROUPS})`);
  const match = base.match(ethnicRegex);
  if (match) base = match[1];

  return pinyin(base, { toneType: "none", type: "array" })
    .join("")
    .toLowerCase()
    .replace(/[^a-z0-9]/g, "");
}
```

### 3.3 数据覆盖范围

- 直辖市：北京、上海、天津、重庆
- 地级市、自治州、盟、地区：约 **340+** 个城市
- 热门城市（HOT_CITIES）保留人工维护的 `districtLabel` 等运营字段

## 4. 服务端定位接口

### 4.1 接口地址

```
GET /api/locate?source=h5|ip|auto&lat={lat}&lng={lng}
```

### 4.2 返回结构

```ts
interface LocateResult {
  success: boolean;
  slug: string;
  name: string;
  source: "h5" | "ip" | "none";
  confidence: "high" | "medium" | "low";
  reason?: string;
}
```

### 4.3 定位优先级

| source | 逻辑 |
|--------|------|
| `h5` | 使用客户端经纬度 → 高德逆地理编码 → 解析城市 → 失败则降级 IP 定位 |
| `ip` | 高德 IP 定位 → ip-api → ipinfo.io |
| `auto` | 同 `ip`，用于首次静默定位 |

### 4.4 IP 定位服务优先级

```ts
async function ipLocate(ip: string | null) {
  // 1. 高德 IP 定位（需配置 GAODE_IP_KEY）
  const gaodeResult = await gaodeIpLocate(ip, key);
  if (gaodeResult) return gaodeResult;

  // 2. ip-api
  const ipApiResult = await tryIpApi(ip);
  if (ipApiResult) return ipApiResult;

  // 3. ipinfo.io
  const ipInfoResult = await tryIpInfo(ip);
  if (ipInfoResult) return ipInfoResult;

  return null;
}
```

### 4.5 环境变量

```bash
# .env.local
GAODE_IP_KEY=你的高德Web服务Key
```

`GAODE_REGEO_KEY` 可选，未配置时回退使用 `GAODE_IP_KEY`。

## 6. 客户端状态管理

### 6.1 AppContext 核心逻辑

```ts
const DEFAULT_CITY_SLUG = "beijing";

// 当前城市始终为 lowercase slug
const [currentCity, setCurrentCity] = useState(DEFAULT_CITY_SLUG);

// 持久化：localStorage + Cookie 双写
const persistCity = useCallback((slug: string) => {
  const lower = slug.toLowerCase();
  setCurrentCity(lower);
  localStorage.setItem("restored_current_city_v1", lower);
  document.cookie = `city_slug=${lower}; path=/; max-age=31536000`;
}, []);

// 首次访问：静默 IP 定位，显示推荐气泡，不强制跳转
useEffect(() => {
  const storedCity = localStorage.getItem("restored_current_city_v1");
  if (storedCity) {
    setCurrentCity(storedCity.toLowerCase());
  } else {
    fetch("/api/locate?source=auto")
      .then((res) => res.json())
      .then((data) => {
        if (data?.success && data.slug) {
          setSuggestedCity({ slug: data.slug, name: data.name || getCityName(data.slug) });
        }
      });
  }
}, []);
```

### 6.2 推荐气泡

```tsx
// src/components/LocationPrompt.tsx
```

## 7. 城市选择弹窗

### 7.1 自动定位流程

```tsx
const handleAutoLocate = async () => {
  setIsLocating(true);

  // 1. 优先 H5 定位
  const position = await h5Locate();
  if (position) {
    const res = await fetch(
      `/api/locate?source=h5&lat=${position.latitude}&lng=${position.longitude}`
    );
    const data = await res.json();
    if (data?.success && data.slug) {
      onSelectCity(data.slug);
      return;
    }
  }

  // 2. H5 失败/未授权时，降级到 IP 定位
  if (h5Error) {
    setLocateError(ERROR_MESSAGES[h5Error]);
  }

  const ipSuccess = await handleIpLocate();
  if (ipSuccess) return;

  setLocateError("定位失败，请手动选择城市");
};
```

### 7.2 错误提示

| 场景 | 提示文案 |
|------|---------|
| 用户拒绝 H5 定位 | “浏览器定位权限被拒绝，已为您切换为 IP 定位” |
| H5 定位超时 | “定位超时，已为您切换为 IP 定位” |
| H5 不支持 | “当前浏览器不支持定位，已为您切换为 IP 定位” |
| H5 解析到未覆盖城市 | “当前城市暂未开通服务，请手动选择附近城市” |
| IP 定位返回未覆盖城市 | “定位服务返回「{城市}」，暂未覆盖该城市（{服务}）” |
| 所有定位服务失败 | “所有定位服务均不可用，请手动选择城市” |

开发环境下还会显示 `debug: {reason}`，便于排查具体失败原因。

## 10. 注意事项与风险

1. **H5 定位需要 HTTPS**：生产环境必须使用 HTTPS，否则部分浏览器会禁用 `navigator.geolocation`。
2. **用户授权体验**：H5 定位仅在用户主动点击“自动定位”后触发，避免首次静默弹窗。
3. **高德 Key 安全**：Key 仅保存在服务端环境变量中，不会暴露到前端。
4. **隐私合规**：IP 定位和 H5 定位都属于位置信息收集，需在隐私政策中说明用途。
5. **国内 IP 服务配额**：高德、ip-api、ipinfo 均有免费额度，生产环境需监控用量。
6. **包体积影响**：引入 `china-division` + `pinyin-pro` 后，首屏 JS 有所增加，后续可考虑构建时预生成城市列表。

## 11. 后续可优化

3. **城市选择器按区域展示**：利用 `CITY_GROUPS` 在弹窗中增加“按区域选择”标签页。

# UI/UX 设计

## 设计理念

**极简寝具循环，透明、卫生、无摩擦**

设计风格追求干净、专业、可信赖，通过克制的色彩和清晰的层级传达卫生安全的核心价值。

---

## 色彩系统

### 主色调

| 颜色 | 值 | 用途 |
|------|-----|------|
| 黑色 | `#000000` | 主按钮、文字、强调 |
| 白色 | `#FFFFFF` | 背景、卡片 |
| 中性灰 | `#F5F5F5` | 次要背景、分隔线 |

### 功能色

| 颜色 | 值 | 用途 |
|------|-----|------|
| 成功绿 | `#10B981` (emerald-400) | 卫生认证、成功提示 |
| 错误红 | `#E11D48` (rose-600) | 未读标记、错误提示 |
| 文字灰 | `#9CA3AF` (gray-400) | 次要文字、占位符 |

### 色彩应用

```tsx
// 主按钮
className="bg-black text-white hover:bg-neutral-800"

// 成功状态
className="text-emerald-400"

// 未读标记
className="bg-rose-600"
```

## 排版系统

### 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 标题 | Plus Jakarta Sans | 现代无衬线，品牌感 |
| 正文 | 系统字体栈 | 性能优先 |
| 代码 | Geist Mono | 等宽字体 |

### 字号层级

| 层级 | 大小 | 用途 |
|------|------|------|
| H1 | 3xl-4xl (30-36px) | 页面主标题 |
| H2 | xl-lg (20-24px) | 区块标题 |
| H3 | lg (18px) | 子标题 |
| 正文 | base (16px) | 主要内容 |
| 辅助 | sm (14px) | 说明文字 |
| 微小 | xs (12px) | 标签、元数据 |

### 字重

| 字重 | 用途 |
|------|------|
| font-bold (700) | 标题、强调 |
| font-semibold (600) | 按钮、导航 |
| font-medium (500) | 正文 |

## 组件规范

### 按钮

#### 主按钮

```tsx
<button className="
  bg-black text-white
  font-semibold text-[13px]
  px-5 py-2.5 rounded-full
  hover:bg-neutral-800
  transition-all active:scale-95
  shadow-sm
">
  发布
</button>
```

**状态**：
- 默认：黑色背景
- 悬停：`neutral-800`
- 按下：`scale-95`

#### 次要按钮

```tsx
<button className="
  bg-white text-gray-600
  font-semibold text-[13px]
  px-4 py-1.5 rounded-full
  border border-gray-200
  hover:border-gray-400
  transition-all
">
  全部尺寸
</button>
```

## 交互设计

### 加载状态

```tsx
// 骨架屏
<div className="animate-pulse bg-gray-200 rounded-xl h-48" />

// 文字提示
<p className="text-gray-400 text-sm">加载中...</p>
```

### 空状态

```tsx
<div className="py-20 text-center border-2 border-dashed border-gray-100">
  <SlidersHorizontal className="w-10 h-10 text-gray-300 mx-auto mb-4" />
  <h3>没有找到符合条件的床垫</h3>
  <p>可以尝试缩短搜索词...</p>
  <button>清除所有筛选条件</button>
</div>
```

### 成功/错误提示

```tsx
// Toast 提示
showToast("已加入收藏夹", "success");
showToast("已移出收藏夹", "error");
```

## 设计原则

### 1. 卫生感

- 大量留白
- 干净利落的线条
- 绿色认证标识

### 2. 透明度

- 价格清晰展示
- 卫生状况透明
- 卖家信息可见

### 3. 无摩擦

- 无需注册即可使用
- 操作流程简洁
- 即时反馈

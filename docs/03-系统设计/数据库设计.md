# 数据库设计

## 数据库选型

**Supabase (PostgreSQL)** - 云端托管 PostgreSQL 数据库，提供实时订阅、行级安全和 RESTful API。

## 数据表设计

### 1. listings（商品表）

存储床垫商品的完整信息。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK, DEFAULT gen_random_uuid() | 商品唯一标识 |
| title | VARCHAR(200) | NOT NULL | 商品标题 |
| brand | VARCHAR(100) | NOT NULL | 品牌名称 |
| price | INTEGER | NOT NULL | 转让价格（元） |
| retail_price | INTEGER | | 原价/零售价 |
| size | VARCHAR(20) | NOT NULL | 尺寸：1.2m/1.5m/1.8m/King/Custom |
| dimensions_text | VARCHAR(50) | | 具体尺寸描述 |
| material | VARCHAR(50) | NOT NULL | 材质：Spring/Latex/Memory Foam/Hybrid |
| thickness_cm | INTEGER | | 厚度（厘米） |
| use_duration | VARCHAR(50) | | 已使用时长 |
| condition | VARCHAR(20) | NOT NULL | 品相：Brand New/Like New/Good |
| hygiene_note | TEXT | | 卫生说明 |
| has_elevator | BOOLEAN | DEFAULT false | 是否有电梯 |
| delivery_option | VARCHAR(50) | | 配送方式 |
| description | TEXT | | 商品详细描述 |
| city | VARCHAR(50) | NOT NULL | 城市（拼音） |
| district | VARCHAR(100) | | 区域 |
| distance_km | DECIMAL(5,2) | | 距离（公里） |
| images | JSONB | | 图片 URL 数组 |
| is_verified_clean | BOOLEAN | DEFAULT false | 是否已验证清洁 |
| is_hygiene_verified | BOOLEAN | DEFAULT false | 是否卫生认证 |
| is_cleaned | BOOLEAN | DEFAULT false | 是否已保洁 |
| wechat_id | VARCHAR(100) | NOT NULL | 卖家微信号 |
| phone | VARCHAR(20) | | 卖家电话 |
| seller_device_id | UUID | | 卖家设备 ID |
| created_at | TIMESTAMPTZ | DEFAULT NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | DEFAULT NOW() | 更新时间 |

**索引**：
```sql
CREATE INDEX idx_listings_city ON listings(city);
CREATE INDEX idx_listings_created_at ON listings(created_at DESC);
CREATE INDEX idx_listings_price ON listings(price);
CREATE INDEX idx_listings_material ON listings(material);
```

### 2. favorites（收藏表）

存储用户收藏的商品记录。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK, DEFAULT gen_random_uuid() | 记录唯一标识 |
| device_id | UUID | NOT NULL | 设备 ID |
| listing_id | UUID | NOT NULL, FK → listings.id | 商品 ID |
| created_at | TIMESTAMPTZ | DEFAULT NOW() | 收藏时间 |

**索引**：
```sql
CREATE INDEX idx_favorites_device_id ON favorites(device_id);
CREATE UNIQUE INDEX idx_favorites_device_listing ON favorites(device_id, listing_id);
```

**唯一约束**：同一设备对同一商品只能收藏一次。

---

### 3. notifications（通知表）

存储系统通知和用户交互消息。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK, DEFAULT gen_random_uuid() | 通知唯一标识 |
| device_id | UUID | NOT NULL | 接收设备 ID |
| type | VARCHAR(50) | NOT NULL | 类型：contact_request/insight/verification/completed |
| title | VARCHAR(200) | NOT NULL | 通知标题 |
| message | TEXT | | 通知内容 |
| detail_url | VARCHAR(500) | | 详情链接 |
| unread | BOOLEAN | DEFAULT true | 是否未读 |
| action_state | VARCHAR(20) | | 操作状态：pending/accepted/declined |
| buyer_name | VARCHAR(100) | | 买家名称 |
| listing_title | VARCHAR(200) | | 商品标题 |
| listing_id | UUID | FK → listings.id | 关联商品 |
| created_at | TIMESTAMPTZ | DEFAULT NOW() | 创建时间 |

**索引**：
```sql
CREATE INDEX idx_notifications_device_id ON notifications(device_id);
CREATE INDEX idx_notifications_unread ON notifications(device_id, unread);
CREATE INDEX idx_notifications_created_at ON notifications(created_at DESC);
```

## 表关系图

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│  listings   │       │  favorites  │       │notifications│
├─────────────┤       ├─────────────┤       ├─────────────┤
│ id (PK)     │◄──────│ listing_id  │       │ listing_id  │
│ title       │       │ device_id   │       │ device_id   │
│ brand       │       │ created_at  │       │ type        │
│ price       │       └─────────────┘       │ title       │
│ size        │                             │ message     │
│ material    │                             │ unread      │
│ city        │                             │ created_at  │
│ images      │                             └─────────────┘
│ wechat_id   │
│ created_at  │
└─────────────┘
```

**关系说明**：
- `listings` 1 : N `favorites` - 一个商品可被多个设备收藏
- `listings` 1 : N `notifications` - 一个商品可产生多条通知
- `favorites` N : 1 `device_id` - 一个设备可收藏多个商品

## Supabase Storage

### listings 存储桶

用于存储商品图片。

| 配置项 | 值 |
|--------|-----|
| 名称 | `listings` |
| 公开 | 是 |

```
listings/

├── {timestamp}-{random}.{ext}
└── ...
```

## 数据迁移

### 创建表 SQL

```sql
-- 商品表
CREATE TABLE listings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(200) NOT NULL,
  brand VARCHAR(100) NOT NULL,
  price INTEGER NOT NULL,
  retail_price INTEGER,
  size VARCHAR(20) NOT NULL,
  dimensions_text VARCHAR(50),
  material VARCHAR(50) NOT NULL,
  thickness_cm INTEGER,
  use_duration VARCHAR(50),
  condition VARCHAR(20) NOT NULL,
  hygiene_note TEXT,
  has_elevator BOOLEAN DEFAULT false,
  delivery_option VARCHAR(50),
  description TEXT,
  city VARCHAR(50) NOT NULL,
  district VARCHAR(100),
  distance_km DECIMAL(5,2),
  images JSONB,
  is_verified_clean BOOLEAN DEFAULT false,
  is_hygiene_verified BOOLEAN DEFAULT false,
  is_cleaned BOOLEAN DEFAULT false,
  wechat_id VARCHAR(100) NOT NULL,
  phone VARCHAR(20),
  seller_device_id UUID,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 收藏表
CREATE TABLE favorites (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id UUID NOT NULL,
  listing_id UUID NOT NULL REFERENCES listings(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 通知表
CREATE TABLE notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id UUID NOT NULL,
  type VARCHAR(50) NOT NULL,
  title VARCHAR(200) NOT NULL,
  message TEXT,
  detail_url VARCHAR(500),
  unread BOOLEAN DEFAULT true,
  action_state VARCHAR(20),
  buyer_name VARCHAR(100),
  listing_title VARCHAR(200),
  listing_id UUID REFERENCES listings(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 降级策略

当 Supabase 不可用时，系统使用以下降级方案：

| 数据 | 降级位置 | 格式 |
|------|----------|------|
| 商品列表 | `config/data.ts` | JSON 数组 |
| 用户发布 | LocalStorage | `restored_listings_v1` |
| 收藏列表 | LocalStorage | `restored_favorites_v1` |
| 设备 ID | LocalStorage | `restored_device_id_v1` |

# 功能需求规格说明书

## 1. 引言

### 1.1 目的

本文档定义床垫二手交易平台（Restored）的功能需求，为开发、测试和验收提供依据。

### 1.2 范围

本系统是一个专注于二手床垫交易的 Web 平台，提供商品浏览、发布、收藏和消息通知功能。

### 1.3 术语

| 术语 | 说明 |
|------|------|
| Listing | 商品列表项，指一个床垫商品 |
| Device ID | 设备唯一标识，用于识别匿名用户 |
| SSR | 服务端渲染（Server-Side Rendering） |
| CSR | 客户端渲染（Client-Side Rendering） |

---

## 2. 系统概述

### 2.1 系统定位

一个无需注册即可使用的二手床垫交易平台，通过设备 ID 识别用户，强调卫生安全和透明交易。

### 2.2 用户特征

| 用户类型 | 特征 | 占比 |
|----------|------|------|
| 买家 | 寻找性价比高的二手床垫 | 70% |
| 卖家 | 出售闲置床垫 | 25% |
| 两者兼有 | 既买也卖 | 5% |

---

## 3. 功能需求

### 3.1 城市浏览模块

#### 3.1.1 功能描述

按城市展示床垫商品列表，支持搜索、筛选和排序。

#### 3.1.2 功能列表

| ID | 功能 | 优先级 | 说明 |
|----|------|--------|------|
| F-001 | 城市商品展示 | P0 | 显示指定城市的所有在售床垫 |
| F-002 | 关键词搜索 | P1 | 支持品牌、材质、标题、描述搜索 |
| F-003 | 尺寸筛选 | P1 | 按床垫尺寸过滤 |
| F-004 | 材质筛选 | P1 | 按床垫材质过滤 |
| F-005 | 价格排序 | P1 | 按价格升降序排列 |
| F-006 | 城市切换 | P1 | 手动选择浏览城市 |
| F-007 | 自动定位 | P2 | 根据 IP 自动识别城市 |

#### 3.1.3 业务规则

- 用户首次访问时自动定位城市
- 定位失败时默认显示北京
- 城市偏好通过 Cookie 保存（有效期 1 年）
- 搜索支持模糊匹配
- 筛选条件可组合使用

## 5. 数据流

### 5.1 商品发布流程

```
用户填写表单
    ↓
前端验证
    ↓
调用 Server Action
    ↓
写入 Supabase（如已配置）
    ↓
写入 LocalStorage（备份）
    ↓
刷新城市页面缓存
    ↓
跳转到城市首页
```

### 5.2 收藏同步流程

```
用户点击收藏
    ↓
更新 LocalStorage（立即）
    ↓
更新 UI（乐观更新）
    ↓
异步调用 API
    ↓
写入 Supabase
    ↓
显示成功提示
```

## 6. 降级策略

### 6.1 降级层级

| 层级 | 正常模式 | 降级模式 |
|------|----------|----------|
| 数据库 | Supabase | LocalStorage + 默认数据 |
| 存储 | Supabase Storage | Base64 编码 |
| 定位 | IP 定位 API | 默认城市（北京） |
| 收藏 | Supabase + LocalStorage | 仅 LocalStorage |

### 6.2 降级触发条件

- Supabase 环境变量未配置
- 网络请求超时
- API 返回错误

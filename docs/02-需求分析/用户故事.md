# 用户故事

## 用户角色

### 1. 买家（Buyer）

寻找二手床垫的个人用户，关注卫生安全、价格和便利性。

**特征**：
- 租房客、学生、新移民
- 预算有限但追求品质
- 重视卫生和健康

### 2. 卖家（Seller）

出售闲置床垫的个人用户，希望快速成交。

**特征**：
- 搬家、换房、出国
- 床垫品质较好，不舍丢弃
- 希望快速处理闲置物品

### 3. 访客（Visitor）

未注册/未登录的匿名用户，可浏览商品。

**特征**：
- 通过设备 ID 识别
- 无需注册即可使用核心功能

## 用户旅程地图

### 买家旅程

```
进入网站
    ↓
自动定位城市
    ↓
浏览商品列表
    ↓
搜索/筛选商品
    ↓
查看商品详情
    ↓
收藏商品 / 联系卖家
    ↓
通过微信/电话沟通
```

### 卖家旅程

```
进入网站
    ↓
点击"发布"
    ↓
填写商品信息
    ↓
上传商品图片
    ↓
提交发布
    ↓
商品展示在城市列表
    ↓
等待买家联系
```
